# Studio animations

Code-driven shorts, character movement and scene experiments I’m working on.

## Making the scenes work

I’ve also been designing studio animations: short scenes built through code, with character movement, choreography and camera work.

## Timing the performance

The work includes dialogue timing, mouth sync and captions, alongside reusable tools for building the scenes. I’m working on how those pieces fit together, from a character’s movement to the timing of a line.

## Work in progress

These are development experiments. The animation tools and source files are not being released with this page.
